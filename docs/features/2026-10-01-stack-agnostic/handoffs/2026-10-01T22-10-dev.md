# U-dev baton — phase 3 (dev-process contract), IN PROGRESS

Branch feat/sa-dev (worktree .claude/worktrees/sa-dev). Started from de5607a.

Design decisions (so far):
- `.bespunky/dev.json` = `{ install?: {cmd, creates}, apps: { <app>: { processes: [{id, cmd (argv array or sh string),
  ports:{name:base}, env?, primary?, ready?, url?: [{param,value,when: always|offset|running|skipped}],
  advice?: [{when: base|offset|contended|always, text}]}] } } }`. Vars: ${PORT:name} ${OFFSET} ${TREE} ${APP}.
  Exported env per process: declared env + PORT_<NAME> + PORT_OFFSET (only when >0). No bare PORT (a Cloud
  Functions worker reads it) — declare env {"PORT":"${PORT:app}"} when a server wants it.
- Offset step = ceil((max-min+1)/1000)*1000 over the app's declared ports; blocks = floor((65535-max)/step).
  Firebase defaults (4000..9199) give 6000 x 9 — identical to the old constants.
- Engine = generator-owned `tools/dev/` (sh shim `dev` + `dev.mjs` + `lib/*.mjs`), Node built-ins only.
  Written by a new workspace generator `dev` (web layer), which also SEEDS a declaration entry for every Nx app
  with a serve composer that lacks one, from fragment providers (generators/dev/fragments/*: angular/nx dev-server,
  firebase emulators). Seeded per process id, never overwritten (the project owns it after).
- `@bespunky/nx-tools:serve` executor = thin wrapper: own options -> engine flags; every other option forwarded
  to the primary process as --k=v (generic, so a Vite leaf gets its own options). `emulators:false` = alias for
  `--skip=emulators`.
- Firebase proxyConfig: moves into the dev-server leaf's options (migration), instead of being sniffed at serve time.
- port-claim gets its own generator/home tools/port-claim/; tab label moves to an Angular-owned `worktree-tab-label`
  generator; playwright generator -> js layer, pinned (shared constant with the shared-browser runtime).
