### R1 — Nx 23 TS-solution mechanics (done; generator runs on 23.2, source read 23.1)
- Detection: `isUsingTsSolutionSetup` (@nx/js ts-solution-setup.js:50-98) = PM workspaces on (package.json `workspaces` / pnpm-workspace.yaml `packages`) AND tsconfig.base.json + tsconfig.json both exist AND tsconfig.json extends './tsconfig.base.json' with empty files/include AND base has `composite` (declaration not false). Exported only from `@nx/js/internal` — not public; recommendation: own a copy of the predicate.
- devkit: updateProjectConfiguration writes project.json if present, else merges into package.json `nx` (no throw). addProjectConfiguration always writes project.json.
- @nx/js:library in TS-solution: adds workspaces glob, root tsconfig.json `references`, lib tsconfig.json(files/include [] + ref tsconfig.lib.json), package.json with `exports["."]` keyed by custom condition (`@org/source` → ./src/index.ts). No project.json, no `paths`. No consumer dep added — consumer needs `"@org/foo": "*"` / `workspace:*`.
- `--preset=ts`: workspaces ["packages/*"], no nx.json workspaceLayout, base has composite + nodenext + customConditions, no paths; tsconfig.json {extends, files:[], references:[]}.
- `@nx/js:typescript-sync` (via @nx/js/typescript plugin's typecheck/build) maintains root refs + project→dep refs. Our generators still owe: workspaces glob, root reference, consumer package.json dependency.

### R2 — @nx/angular 23 vs TS-solution (done, verified in scratch)
- Guard `assertNotUsingTsSolutionSetup` (validations.js:23-38) only in init, application, library, host, remote. Workspace-wide (root-config check). Escape hatch printed in the error: `NX_IGNORE_UNSUPPORTED_TS_SETUP=true`.
- With the env var: `app` → classic project.json island, no package.json; `nx sync` adds it to root references; importing a TS-solution package (`exports` with dev condition) → `nx typecheck`/`nx build` pass. component + setup-ssr work without the env var; library refused without it.
- Upstream: no fix planned (nrwl/nx#29940, #30540, angular-cli#30446). Env var undocumented → fixture test is our tripwire.
