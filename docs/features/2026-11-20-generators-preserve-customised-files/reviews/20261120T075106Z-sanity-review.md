# Sanity review — generators-preserve-customised-files

Mode: fix. Scope: `git diff origin/development...HEAD` on `fix/generators-preserve-customised-files`.

## Frame

A consumer's upgrade rewrote three files it had customised (DS `src/index.ts`, DS `STRUCTURE.md`, Angular `worktree-tab-label.ts`), because nx-tools owned them wholly. The change introduces HOUSE REGIONS (`@bespunky/<name>:start` … `:end`, one helper `_utils/house-region.ts`): absent → seed whole; region present → rewrite region only; no region → project's, untouched. house-doc's CLAUDE.md pointer and design-system-styles' use/theme blocks move onto the helper. Migration 0.56.0 `mark-house-regions` converts stock files (any frozen historical revision) to the 0.56.0 shape, moves house export statements of a non-stock barrel into a region, and otherwise strips the false header and reports. Payload 0.56.0.

Decisions (user's, not findings): regions over seed-once; marker grammar; rule absent/region/no-region; tab label `badgeStyle()` seam; migration shape as above.

Verification: test-migrations, test-generators, test-layers, test-scaffold, check-descriptions, check-script-modes. Dogfood running separately (owed again after fixes).

## Lenses

- R1 migration correctness on real shapes
- R2 helper + generators correctness/idempotence

## Findings and outcomes

All high/medium findings went to the adversarial verifier (V1), which reproduced each one against HEAD with its own compiled payload. None was refuted.

### Fixed

- **M1 (high), stands.** `matchStock` captured single-use tokens as `.*?` over whitespace-stripped text, so a project line written where a value sits (a const after `MAIN_TREE_SLUG`, an `@use` beside the stock one, a sentence after "The design phase") was absorbed and the customised file was rewritten as stock. **Fix:** a token now matches only its grammar (`[A-Za-z0-9@/.*-]+?`). `designPhaseSkills` matches exactly its frozen text or nothing. Cases added per token.
- **M2 (high), stands.** Prettier (run by every earlier formatFiles) turns the html fence's `<link>` into `<link />`, so no prettier-formatted Angular STRUCTURE.md matched stock. Every Angular consumer would have been told the file was theirs forever. **Fix:** `flatten` folds a void tag's `/>` and where blockquote `>` markers fall. Where the workspace resolves prettier, the rung also tries each stock shape as that prettier formats it under the file's own config. Fixtures frozen from prettier 3.6.2 `{singleQuote:true}`. A by-hand matrix (6 configs × 14 shapes) gave 14/14 for every config, except `semi:false`, which only the prettier path recognises (14/14).
- **M3 (high), stands.** The clash check missed a trailing comment, a project `export class`/`export type`, and a local re-export. In each, the region exported a name twice. **Fix:** refuse when the rest of the file (comments stripped) names any export of the region. `EXPORT_STATEMENT` accepts a trailing comment. 3 cases added.
- **M4 (medium), stands.** House comments were left orphaned below the region, and the old header was kept. **Fix:** each moved statement takes the stock comment directly above it. A stock header becomes the 0.56.0 header, filled with the header's own values. An exact-output case was added on the reporter's shape.
- **H1 (high), H2 (med-high), stand.** A prose mention of a marker counted as a marker. A quoted `house-tooling:end` above the pointer grew a new CLAUDE.md pointer on every run, and a quoted `:start` swallowed project lines. **Fix:** a marker line must open a comment with the marker (`//`, `/*`, `<!--`, `#`). The end is the first one after the start. `regionNames` reports whole regions only. Cases added, including a two-run house-doc case.
- **H3 (medium), stands.** Damaged regions were treated silently as `unowned`. **Fix:** a new `regionState` and a `damaged` sync outcome. The design-system and tab-label generators warn (`DAMAGED_REGION`). The rung skips only on a whole region, and warns on a damaged one.
- **H4 (medium), stands.** Out-of-order markers in a stylesheet prepended a second `@use` block. **Fix:** splice at the first marker and drop the other.
- **CRLF (low).** Both the helper and the rung now write the region in the file's own line endings. `FALSE_HEADERS` consume `\r?\n`.
- **Freeze (R3#5).** The rung's pointer table is now frozen in the rung (`POINTERS`) instead of read from the generator's live table.
- **Docs sweep.** CLAUDE.md (three classes) and README (class table) gained the house-region rule. Updated: the `layers/angular.ts` comment, the `generators.json` design-system description, the migrations.json description (dual scope), the provenance wording in the rung header, and an additive DECISION.md correction (`badgeStyle()`, not `badgeColors()`).
- **Tests.**
  - Exact-output assertions for the stock cases.
  - Prettier-formatted fixtures (`tools/test-migrations/fixtures/0.56.0-prettier/`).
  - Swallow cases.
  - Interleaved, CRLF, dropped-export and damaged cases.
  - Helper grammar cases.
  - The dogfood seed asserts the barrel's region and single comments.

### Needs decision

- **M5 / R1#5.** A barrel that dropped a house export gets it back with the region. It is now named in the report. Whether it should instead fall to case 3 is the user's call.
- **R2#3.** Should a plain `unowned` shared file be reported on every upgrade?
- **R1#8 / R3#7.** The `layer: "design-system"` rung also migrates the angular tab label. It is metadata only, and the description now says so. The alternative is to split it into an `angular` rung.

### Rejected / left

- **R2#9 / R3#3** (inline-house-sections keeps the exact pointer prefix). This is the file's deliberate self-contained migration contract. With the tightened grammar, both rules agree on every real pointer.
- **R1#6** (whitespace inside TS strings folded away). This is a tolerance trade-off, and realistic edits there also change non-whitespace. Left.
- **R2#8** (STRUCTURE.md templates not prettier-stable). The net result is idempotent, since Nx drops the no-op write. Formatting the project's half is pre-existing.
- **R1#10** (`export *` ignored by the clash check). It is legal TS: the explicit export wins.
- **Pre-existing:** a lone or out-of-order `design-system:use` marker leaves the old `@use` line under the new block. This was the case before this change too.
