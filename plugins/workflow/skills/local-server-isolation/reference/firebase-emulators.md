# Worked example — the Firebase emulator suite

> Applies to projects wearing the `firebase` layer (their `HOUSE.md` stamp lists it in `layers=`). The generic fixed-port-backend rules live in the SKILL; this is them applied to Firebase.

In a house project the browser reaches every emulator through the app's own origin (the dev server relays it to *its* stack's suite), but the suite itself binds **fixed** ports, which a random *app* port doesn't move. The house launcher (`tools/emulators.sh`) first runs `tools/reap-emulators.sh`, which kills only **orphaned** emulator processes (reparented to PID 1, left by a crash); when a **live, owned** suite holds the ports it names the holder, kills nothing, and the launch stops. So naively "serving to test" on the base ports fails against the user's running suite — it never takes it down, and you must not either.

- **Never start a second suite on the default ports** — it collides with the user's and is refused. If you need emulators, run your own on a **shifted port set** (below), so you never collide with theirs. Never kill their suite to free the ports.
- **Skipping the suite is not reusing theirs.** `--no-emulators` (Nx face) / `--skip=emulators` (the engine) serves the app with `?emulate=none`: every Firebase service resolves to the **real** backend. That is a deliberate choice for real/staging data — never a way to borrow the running suite, and never against production.
- In a house project, **`<serve> <app> --port-offset=auto`** (`<serve>` is what HOUSE.md names: `<pm> nx serve` for an Nx-served app, else `tools/dev/dev serve`) shifts the whole declared stack (the app + the emulator suite when the app's declaration lists it, including the hub/logging ports) onto a stable, verified-free port block, and reaps only *its own* shifted ports — so it coexists with the developer's suite instead of reaping it. Open the app at the URL it prints (or the worktree's `<slug>.localhost` domain): its dev server relays to the shifted suite, so the page needs no offset of its own. Prefer this over hand-rolling an offset.
