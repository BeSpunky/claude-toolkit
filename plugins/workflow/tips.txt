# Spinner tips for this plugin, shown now and then while Claude works (see plugins/bespunky/hooks/tips.mjs).
# One tip per line; blank lines and lines starting with # are ignored. Keep each short enough to glance at.

Back after a break? Ask "where did I leave off?" and project-standing works it out from git and feature packages
Run /standing for a pane of every feature package, live, dormant or concluded, with a Resume button for each
Context getting long? Say "hand this off" to write a baton a fresh session can resume from
Unrelated requests get their own git worktree off your integration branch automatically, so branches never mix
Trunk, staged, gitflow or maintained releases? Say "simplify our branches" and Claude checks CI and history before proposing a branch model
Every effort's notes, mocks and decisions live in docs/features/<date>-<slug>/, next to its branch
Big task? Claude can split it into subagents running in parallel; you can set the agent budget
Testing a server? The house rule binds a random port, so the dev server you started by hand is never clobbered
The status line shows your branch in the declared model (feat/x → development → main) and warns on a protected line
Compacting? The checkpoint the PreCompact hook saves pops up as a toast with its path, so you know where it went
When Claude proposes landing your branch, a merge gate appears above the prompt: Land, Land & promote, Push, or Not yet
Have Firebase App Hosting? branches.mjs evidence --app-hosting shows which branch each backend rolls out from
